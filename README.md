# 🏛️ Dashboard Sarpras GKPI JK Depok

Dashboard Sarana & Prasarana untuk Tim Sarpras GKPI Jemaat Khusus Depok.

## ✨ Fitur

- 📊 Beranda dengan KPI & Charts
- 📦 Manajemen Data Aset (Publik + Admin Full)
- ➕ Input Aset baru
- 📅 Jadwal Pemeliharaan
- 📣 Lapor Sarpras (via QR Code + Admin Mode)
- 💰 Anggaran tahunan
- 👥 Keanggotaan Tim
- 📊 Laporan Mingguan (CRUD)
- 📄 Laporan Tahunan (PDF Archive)

## 🛠️ Tech Stack

- HTML5 + Bootstrap 5
- Chart.js (visualisasi)
- Google Sheets (database)
- Google Apps Script (backend API)
- Google Drive (file storage)
- PWA (installable di HP)
